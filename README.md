# Data and Systems Security – Course Repository

This repository contains all theoretical and practical materials from the **Data and Systems Security** course.

It includes lecture slides, assignments, lab work, project documentation, security analysis exercises, and final course materials completed throughout the semester.

---

# 📚 Course Overview

The Data and Systems Security course introduces the fundamental concepts, principles, threats, technologies, and protection mechanisms used to secure modern computer systems, networks, wireless environments, mobile devices, and digital information.

The course combines both theoretical and practical aspects of cybersecurity, covering information security foundations, threat analysis, network attacks, wireless security, cryptography, encryption systems, public-key infrastructures, and modern security practices.
